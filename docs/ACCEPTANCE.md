# Acceptance

The project goal is met when all of these are true and `npm run validate` passes:

1. A new game shows an unofficial acceptance letter, a chosen origin, and a train that arrives at Middlebury station.
2. Character creation offers inclusive appearance options and accessibility options, including a wheelchair, and they persist.
3. The escort from the station through Triangle Park to the dorm is walkable on a pixel map and completable with the wheelchair.
4. The dorm can hold unpacked items and doodads across reload.
5. Campus objectives (dining, library, seminar) can be finished without town already being open.
6. Town, including the movie theater, opens from Triangle Park only after those objectives. The boundary wording is labeled as the game's framing.
7. A season toggle changes the map and does not change quests.
8. Snow Bowl is a later trip with an optional minigame that cannot soft-lock the story.
9. The notebook records a seminar note. A question reveals only a response stored on that lesson.
10. No NPC uses a real person's likeness unless the likeness gate names them.
11. The UI does not use Middlebury logos.

Until then, the loop continues.
