# Acceptance

The project goal is met when all of these are true and `npm run validate` passes:

1. A new player can create a character and continue that same character after reload.
2. A headless run completes the orientation quest using only public game actions.
3. Dining halls, first-year residence names, and orientation support roles that the game states as true are `verified` facts.
4. The notebook records a note in the seminar and shows it afterward.
5. Asking a question reveals only a response stored on that lesson.
6. A sidequest tied to an unselected interest does not appear.
7. Downtown and outdoors are locked on a fresh save and open only through play.
8. No NPC is a `sourced-person` unless the people gate is approved.
9. No lesson is `official` unless the LMS gate is approved.
10. The UI does not use Middlebury logos.

Until then, the loop continues. Partial phases are not a reason to stop.
